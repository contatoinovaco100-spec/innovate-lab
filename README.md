# Innovate Finance 🚀

Uma plataforma web moderna e minimalista de organização financeira pessoal.

## 🌟 Funcionalidades

- **Dashboard Intuitivo**: Visualize seu saldo, entradas, saídas e quanto sobrou no mês.
- **Gráfico de Evolução**: Acompanhe seu crescimento financeiro ao longo dos meses.
- **Transações Recentes**: Lista detalhada com categorias e ícones.
- **Adição Rápida**: Adicione receitas e despesas com apenas alguns cliques.
- **Metas de Economia**: Acompanhe o progresso dos seus objetivos financeiros.
- **Categorias Inteligentes**: Alimentação, Transporte, Lazer, Contas Fixas, Saúde, Compras e Extras.

## 🛠️ Tecnologias

- **React + TypeScript**
- **Vite** (Build tool)
- **Vanilla CSS** (Design System customizado)
- **Lucide React** (Ícones premium)
- **Recharts** (Gráficos dinâmicos)
- **Framer Motion** (Animações suaves)

## 🚀 Como rodar

1. Entre na pasta do projeto:
   ```bash
   cd innovate-finance
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

4. Abra `http://localhost:5173` no seu navegador.

## 🎨 Design

O design foi focado em **Clareza**, **Elegância** e **Facilidade de Uso**, utilizando conceitos de glassmorphism e uma paleta de cores harmoniosa para proporcionar uma experiência premium.
